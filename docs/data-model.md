# Модель данных Психосерфа

Что хранит приложение и как это связано. Основа для базы данных (PostgreSQL, Р-30).
Решения, на которых построено: Р-2, Р-5, Р-6, Р-24, Р-25, Р-26, Р-27, Р-29, В-18, В-20.

Статус: черновик на согласовании, 2026-10-27.

## Схема

```
users ─┬─< auth_identities        (как человек входит: сейчас только Telegram)
       │
       └─< diaries >── sports      (один дневник на каждый вид спорта)
              │
              └─< entries ─< entry_options >── options
                  (тренировка)                 (эмоции и мотивация из Словаря Яны)
```

`─<` означает «один ко многим».

## Таблицы релиза 1

### users — пользователь
| Поле | Что это |
|---|---|
| id | Наш собственный номер пользователя (не Telegram ID, Р-29) |
| display_name | «Как тебя называть», необязательно. Пусто = «психосёрфик» (В-18) |
| consent_at | Когда человек дал согласие на обработку данных (152-ФЗ) |
| settings | Мелкие настройки интерфейса, например свёрнут ли блок «Что значат мешочки» (В-17) |
| created_at | Когда зарегистрировался |

Удаление по запросу: удаляем пользователя, всё остальное удаляется вместе с ним.

### auth_identities — способ входа
| Поле | Что это |
|---|---|
| user_id | Чей это вход |
| provider | Откуда вход: `telegram` (позже, если понадобится, `email`) |
| provider_user_id | ID человека в Telegram |

Отдельная таблица нужна, чтобы при блокировке Telegram добавить вход по почте и не потерять дневники (Р-29).

### sports — список видов спорта
| Поле | Что это |
|---|---|
| code | Короткий код, например `surf`, `running` |
| name | Название на экране |
| sort_order | Порядок в списке |

19 видов из экрана Яны (И-25). Свой вид спорта сюда не попадает, он хранится в дневнике.

### diaries — дневник одного вида спорта
| Поле | Что это |
|---|---|
| user_id | Чей дневник |
| sport_id | Вид спорта из списка, или пусто для своего |
| custom_sport_name | Название своего вида спорта |
| color | Цвет линии на графиках (Р-6) |
| created_at | Когда начат |

### entries — одна тренировка
| Поле | Что это |
|---|---|
| diary_id | В каком дневнике |
| training_date | Дата тренировки, человек может выбрать прошлую (И-29) |
| created_at | Время сохранения. Порядок тренировок внутри одного дня (Р-26) |
| tone | Шаг 1: `good` «Скорее хорошо», `hard` «Скорее непросто», `numb` «Ничего не чувствую» |
| motivation | Шаг 3: `forward` «Тянет вперёд», `not_forward` «Не тянет» |
| emotion_note | Заметка к эмоциям (Р-27) |
| motivation_note | Заметка к мотивации (Р-27) |

### options — варианты эмоций и мотивации
| Поле | Что это |
|---|---|
| code | Номер из Словаря Яны: `Сл-1` … `Сл-59` |
| label | Текст на кнопке |
| kind | `E+`, `E-`, `M+`, `M-` |
| is_active | Можно ли выбрать сейчас (старые варианты не удаляем, чтобы не сломать прошлые записи) |

Источник правды — лист «Словарь». Слова-синонимы из него понадобятся в релизе 2 для подбора советов.

### entry_options — что выбрано в тренировке
| Поле | Что это |
|---|---|
| entry_id | Тренировка |
| option_code | Выбранный вариант |

Сюда же попадает «Было и другое?»: это просто варианты другого знака.

## Что не храним, а считаем

Точки графиков (Р-25), мешочки (И-23), анализ под графиком (В-16) и красный флаг (И-20) считаются из записей каждый раз. Если формулу поменяем, старые данные пересчитаются сами.

Формула точки эмоций: знак = `tone`, высота = доля выбранных эмоций этого знака.
Формула точки мотивации: знак = `motivation`, высота = доля выбранных вариантов этого знака.
`numb` = 0.

## На потом (не делаем в релизе 1)

- **periods** — периоды: сборы, межсезонье (Р-24). Таблица добавляется без изменения остальных.
- **subscriptions** — подписка и пробный период (релиз 2, В-12).
- **advice / advice_shown** — пул советов Яны и что кому показали (релиз 2).

## Открытые вопросы

1. При «Ничего не чувствую» спрашиваем ли мотивацию (шаг 3)? → Яна
2. Красный флаг: 2 раза подряд «ничего» в одном спорте или в любых? → Яна
3. Можно ли выбрать тон «Скорее хорошо» и не отметить ни одной эмоции? Если да, где точка на графике? → Яна
