# Психосерф

Telegram Mini App: дневник состояния после тренировок с советами спортивного психолога.

## Структура

- `web/` — экраны приложения (React + Vite)
- `docs/` — модель данных и технические заметки

Решения и задачи проекта — в таблице «Психосерф база» в Google Диске.

## Запуск экранов на своём компьютере

Нужен Node.js (версия LTS).

```
cd web
npm install
npm run dev
```

Открыть в браузере адрес, который покажет терминал (обычно http://localhost:5173).
