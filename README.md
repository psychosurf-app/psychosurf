# Психосерф

Telegram Mini App: дневник состояния после тренировок с советами спортивного психолога.

## Структура

- `web/` — экраны приложения (React + Vite)
- `docs/` — модель данных и технические заметки

## Правила кода (Р-33)

Тестовая сборка работает без сервера, сервер добавляется позже. Чтобы переход не стал переписыванием:

- `web/src/storage/` — единственное место, где сохраняются и читаются данные. Экраны не знают, где лежат записи. Сменить хранилище = заменить адаптер в `storage/index.js`.
- `web/src/advice/` — единственное место, откуда приходит совет психолога. Сейчас всегда «закрыто», в релизе 2 — с сервера.
- `web/src/telegram.js` — единственное место, которое говорит с Telegram (Р-29).
- У каждой записи есть `version` (формат данных). Поменяли формат — подняли `SCHEMA_VERSION` и дописали `upgrade`.
- Платные советы в код приложения не кладём: любой может открыть код страницы.

Решения и задачи проекта — в таблице «Психосерф база» в Google Диске.

## Запуск экранов на своём компьютере

Нужен Node.js (версия LTS).

```
cd web
npm install
npm run dev
```

Открыть в браузере адрес, который покажет терминал (обычно http://localhost:5173).
